A short note

I'm a machine learning engineer at Qualcomm R&D, after an M.Tech at the Indian Institute of Technology Hyderabad. I work on inference and sensitivity analysis for large language models, and on loading weights only when a layer needs them. That cut peak RAM by 90%. Before that, at Primera, I built a RAG insurance accelerator for claim approvals and denials.

Work

  • Contribute to Microsoft Olive-Recipes by upstreaming Mistral support and carry out sensitivity analysis for QAIRT, enabling optimized AI model deployment and improved inference performance on Snapdragon NPUs.
  • Implement deferred weight loading, so model weights are loaded only when needed instead of loading the full model into RAM. Convert model tensors on demand, which reduces the number of weights and intermediate buffers kept in memory at the same time. Combined with model compression, this reduced peak RAM by 90% and improved inference throughput.
  • Build custom operators in DirectML to improve ML inference performance on ARM-based Windows on Snapdragon (WoS) devices.
  • Developed a RAG-based insurance accelerator automating claim approvals and denials using Azure OpenAI and Sentence Transformers.
  • Improved system accuracy by implementing a sliding window technique with LlamaIndex.
  • Integrated with Azure AI for data management and deployed via FastAPI with a Streamlit interface.

The sentence the window cut in half

A faculty development session on retrieval-augmented generation. The hour stayed on one failure: the model answers from a passage you retrieved, and that passage stops one sentence before the fact that decides the question. We walked through chunking, what a sliding window keeps, and how to tell a grounded answer from a fluent one.
