A short note

I like the part of machine learning that shows up after the notebook looks finished. A weight file that is too big for the device, a retrieval stack that quotes the wrong clause, a score that only holds on the training split. At Qualcomm that shows up as compilers, memory, and operators. Before that, at Primera, it was an insurance claim that had to be drafted from the policy rather than from a blank prompt.

The projects below are the same habit on my own time. Tune a small model, measure it on a split I did not train on, and keep the number even when the fancy version loses.

Work

The work is deployment. A model that trains is not the same object as a model that runs on a Snapdragon NPU, and most of the surprises live in that gap.

I added Mistral to the Microsoft Olive recipe set and ran sensitivity checks for QAIRT, so we could see which layers the compiler actually cared about before anyone tried to ship it. On the runtime side I stopped reading the whole weight file at startup. A layer loads its tensors when it needs them, and compression sits on that path. Peak RAM fell by 90%, and throughput went up with it. I also write DirectML operators for inference on Windows on Snapdragon, the cases where the graph reaches a kernel the stack does not have yet.

Primera wanted a desk that could draft an insurance approval or a denial from the claim file, not from a generic answer. I built the retrieval path with Azure OpenAI and sentence transformers, and used a sliding window in LlamaIndex so the model saw the clause that decided the claim instead of a chopped paragraph. The store was Azure AI. FastAPI and Streamlit were the front of it.

Repository

State of health on the Oxford cells, defined from each cell’s own first discharge rather than the nameplate. A plain LSTM-GAN and a bidirectional LSTM with a WGAN both invent extra curves. The estimator is then packed from float32 to int8, once with post-training quantization and once with quantization-aware training. On the held-out cell the float bidirectional model is the best of the saved runs. The int8 copy is smaller. One of the quantized runs got worse, and the write-up says so.

Repository

SSD MobileNet is the detector this project keeps, trained on mixes of those countries rather than on one of them and hoped across the rest.

A BiLSTM-CRF for a target domain that does not have enough labeled text of its own. Multi-task learning shares what transfers. A mixture of entity experts is there so a person tag and a drug tag do not have to share one stubborn representation.

The sentence the window cut in half

A faculty development session on retrieval-augmented generation. The hour stayed on one failure: the model answers from a passage you retrieved, and that passage stops one sentence before the fact that decides the question. We walked through chunking, what a sliding window keeps, and how to tell a grounded answer from a fluent one.
